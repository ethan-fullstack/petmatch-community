# Bloque 08 — Administración, reportes y calidad del software

Cuando una aplicación incorpora necesidades administrativas aparecen preguntas adicionales sobre permisos, consultas globales, exportaciones y calidad. Este bloque explica los mecanismos de ingeniería que resuelven esos problemas sin depender de un cronograma de formación.

PetMatch es el caso de estudio; el objetivo es comprender decisiones transferibles, sus costos, sus límites y la forma de comprobarlas.
